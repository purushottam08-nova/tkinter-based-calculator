# 🧮 Tkinter Calculator

A modern desktop calculator application built with **Python** and **Tkinter**, designed with a clean interface, modular architecture, and reliable calculation logic.

The project focuses on applying Python fundamentals, Object-Oriented Programming, GUI development, and software project structure in a practical application.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal calculations
- % Percentage calculations
- ± Positive/negative toggle
- ⌫ Backspace functionality
- 🧹 Clear functionality
- ⚠️ Division-by-zero error handling
- ⌨️ Keyboard input support
- 🕘 Calculation history
- 🎨 Multiple UI themes
- 🖱️ Interactive button states
- 📱 Clean and responsive calculator layout
- 🧩 Modular project architecture
